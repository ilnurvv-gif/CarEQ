Car EQ — эквалайзер + Bass Boost для Android-магнитол

СБОРКА ОНЛАЙН (бесплатно, GitHub Actions):
1. Зарегистрируйтесь на github.com.
2. New repository -> создайте репозиторий (Public).
3. Add file -> Upload files -> перетащите ВСЁ содержимое папки CarEQ (распакованной).
   Папка .github должна попасть в репозиторий (если нет — Add file -> Create new file,
   имя: .github/workflows/build.yml и вставьте содержимое файла).
4. Вкладка Actions -> Build APK -> дождитесь зелёной галочки (3-5 минут).
5. Откройте запуск -> внизу Artifacts -> CarEQ-apk -> скачайте zip -> внутри app-debug.apk.
